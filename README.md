# 학원소개 AI 문구 생성 시스템

이투스247학원 가맹마케팅지원팀에서 지점별 학원소개 문구를 만들고, 담당자가 후보를 골라 검수하는 흐름을 시연하는 React·TypeScript 프로토타입입니다. `샘플 결과`로 표시되는 문구는 지점 입력과 브랜드 가이드를 반영한 템플릿 예시입니다.

## 실행

Node.js 20.19 이상인 20.x 또는 Node.js 22.12 이상이 필요합니다. 저장소 루트에서 실행합니다.

```bash
npm ci
npm run dev
```

터미널에 표시되는 개발 서버 주소를 브라우저에서 엽니다. 기본 포트는 `5173`입니다. 클라우드 실행 환경에서 브라우저 미리보기가 필요하면 `npm run dev -- --host 0.0.0.0`으로 실행합니다.

```bash
npm run build
```

빌드는 TypeScript 타입 검사를 실행하고 배포용 파일을 `dist/`에 생성합니다. 빌드 결과를 브라우저에서 확인하려면 `npm run preview`를 실행합니다.

## 주요 기능 테스트

1. **지점 정보와 영역 선택.** 지점명을 `수원점`으로 바꾸고 기존 키워드를 삭제한 뒤 `개별 상담`과 `주간 계획`을 추가합니다. 근거 자료로 `학부모에게 매주 학습 일지를 전달합니다.`를 입력합니다. `지점 강점`만 선택하고 **샘플 문구 생성**을 누릅니다. 해당 영역 탭 하나와 후보 3개가 표시되고, 후보에 입력한 정보가 반영되었는지 확인합니다. 지점명이나 키워드가 비어 있거나 영역을 모두 해제하면 오류 안내가 표시됩니다.
2. **브랜드 가이드.** **브랜드 가이드**를 열어 문체를 `친근한`으로 바꾸고 다시 생성합니다. 이전 결과와 문체를 비교합니다. 금지 표현에 `학습 일지`를 추가하고 다시 생성하면 해당 표현이 후보에서 제외됩니다. 최소 글자 수를 최대 글자 수보다 크게 설정하면 입력 오류가 표시됩니다.
3. **문구 선택, 편집, 복사.** 후보의 **선택**을 눌러 편집 영역을 열고 문구를 수정합니다. 편집 중 글자 수가 바뀌는지 확인합니다. 금지 표현을 넣거나 길이 범위를 벗어나면 안내가 표시됩니다. 문구를 정리한 뒤 **복사**를 눌러 텍스트 편집기에 붙여넣고 수정본과 같은지 확인합니다.
4. **검수와 이력.** 선택한 후보의 **검수 기록**으로 이동해 `수정 요청`을 선택합니다. 사유 없이 저장할 때는 입력 안내가 표시됩니다. 사유를 입력해 저장한 뒤 브라우저를 새로고침하고 **검수 기록**에서 지점명, 문구, 검수 결과, 사유가 남아 있는지 확인합니다. `반려`를 선택하거나 편집한 문구를 승인할 때도 사유가 필요합니다.

검수 이력은 현재 브라우저의 `localStorage`에 저장됩니다. 같은 브라우저에서 같은 주소로 접속할 때 이력을 다시 볼 수 있습니다.

## 실제 AI 연결 지점

`src/generator.ts`에 생성 요청과 응답 타입, `CopyGenerator` 인터페이스가 정의되어 있습니다. 현재 구현체인 `sampleGenerator`는 지점 정보, 선택 영역, 브랜드 가이드를 받아 영역별 후보를 반환합니다. 실제 모델을 연결할 때는 서버 API를 호출하는 구현체를 추가하고, `src/App.tsx`의 생성 호출 및 샘플 표시를 연결 상태에 맞게 갱신합니다. 모델 API 인증은 서버에서 처리합니다.
